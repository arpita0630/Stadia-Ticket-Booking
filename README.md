# 🎟️ Stadia Ticket Booking

Stadia Ticket Booking is a responsive React-based web application that provides a modern ticket booking experience for **sports matches** and **movies**. The project focuses on creating an intuitive user interface with seamless navigation, dynamic booking pages, and a clean user experience.

## 🚀 Features

- 🏏 Browse upcoming sports matches
- 🎬 Browse available movies
- 🎟️ Interactive ticket booking interface
- 💰 Dynamic ticket pricing
- ✅ Booking confirmation page
- 📱 Fully responsive design
- ⚡ Fast navigation using React Router
- 🎨 Modern UI built with Tailwind CSS

---

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/arpita0630/Stadia-Ticket-Booking.git
```

Navigate into the project directory:

```bash
cd Stadia-Ticket-Booking
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open your browser and visit:

```
http://localhost:5173
```
